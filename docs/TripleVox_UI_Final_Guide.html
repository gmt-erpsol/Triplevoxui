01. Welcome & what this app is / is not

TripleVox Platform (triplevox_platform) is the white-label Desk shell for Frappe v16 deployments used by TripleVox Engineering PLC and sister factories (TITA, BRG, and future clients).

Product identity

  • App title: TripleVox Platform
  • GitHub: https://github.com/gmt-erpsol/Triplevoxui
  • Installed folder name must be triplevox_platform (not Triplevoxui)
  • Static assets: /assets/triplevox_platform/...
  • Publisher: TripleVox Engineering PLC · License: MIT · Requires: frappe, erpnext, hrms

What this app is

CapabilityExamples
Desk chrome & themeCSS variables, welcome home, clock, module icons, watermark pill, footer
Multi-company SaaS shellCompany switcher, onboarding wizard, login company picker
Client theme profilestita / brg / demo in client_theme.py
Print identityTripleVox Print Formats, Letter Head pack, Jinja branding helpers
Role packsShop Floor, QC, Ops Admin, Workspace Viewer
UX polishRecent activity, form float rail, sidebar hide on Desktop, check-in geolocation fix

What this app is not

Not responsible forBelongs in
MES / factory shop-floor workflowstitacustom (or future BRG domain app)
Core accounting, stock, CRM logicERPNext
HR / payroll / leave enginesHRMS
Full security matrix for every DocTypeERPNext roles + Custom DocPerm (packs are starters)
Infrastructure / backups / SSLBench / nginx / ops runbooks
Info

Think of TripleVox Platform as the skin + sister-company cockpit. Domain features live in ERPNext/HRMS/titacustom; this app makes one bench site feel like a branded multi-factory product.

Audience for this guide

  • Implementers setting up a new PC or new sister company
  • System Managers who assign role packs and print packs
  • Support engineers debugging branding, cache, or migrate side-effects

02. Architecture overview (Desk shell vs titacustom vs ERPNext/HRMS)

A TripleVox production site is a layered Frappe Bench stack. Understanding which layer owns a feature prevents wrong-repo edits and wrong-app tickets.

Layer diagram (conceptual)

Browser (Desk / login)
    |
    v
triplevox_platform     <- CSS/JS, boot branding, switcher APIs, prints, roles
    |
    +-- titacustom     <- TITA manufacturing MES / custom DocTypes (optional)
    +-- erpnext        <- Accounting, Stock, Selling, Buying, Manufacturing base
    +-- hrms           <- HR, Payroll, Leave, Employee Checkin
    +-- frappe         <- Framework, Desk shell, Permissions, Website, Print engine
         |
         v
      MariaDB + Redis + sites/YOURSITE

Responsibility matrix

ConcernAppNotes
Login accents / company pickertriplevox_platformwww/login.html, tvx_login.css/js
Desk logo (product)triplevox_platformAlways TripleVox mark via profile logo_url
Watermark pill (client)triplevox_platformclient_logo_url / company map
Work Order / Job Card domain UItitacustom + ERPNextUI shell nests icons/sidebar
Employee Checkin geolocation blinktriplevox_platformdoctype_js for Employee Checkin
Print PDF company logotriplevox_platform print_brandingResolves from document Company
Workspace edit lockWorkspace Viewer roleoverrides get_workspaces

Boot payload

On every Desk session, boot_session injects frappe.boot.triplevox from client_theme.get_boot_payload(). Front-end scripts (triplevox_desk.js, tvx_saas_ui.js) read that object for theme CSS variables, watermark, welcome copy, and switcher company list.

Warning

Do not put sister-company logos into Desk logo_url. Desk product chrome stays TripleVox; client marks go to watermark / prints / login preview.

04. Install Frappe Bench from scratch (high-level official steps + links)

Follow the official Frappe Framework installation guide for your platform. Below is the shape of a typical Linux / WSL Ubuntu flow for Frappe v16 — always verify versions against current docs.

  1. Update apt and install OS dependencies listed in the official guide.
  2. Install and secure MariaDB; create a DB user for Bench if required by your playbook.
  3. Install Redis, Node (via nvm or nodesource as documented), Yarn.
  4. Install wkhtmltopdf with patched Qt if you need PDF generation from Desk.
  5. Install frappe-bench via the documented method (pipx install frappe-bench or equivalent).
  6. bench init --frappe-branch version-16 frappe-bench (confirm branch for your target).
  7. cd frappe-bench && bench start (dev) or set up production supervisor/systemd + nginx.
# Illustrative only — confirm against official docs
sudo apt update
# ... install python, mariadb, redis, curl, git, wkhtmltopdf ...
pipx install frappe-bench
bench init --frappe-branch version-16 frappe-bench
cd frappe-bench
bench start

Official references

  • Installation: https://frappeframework.com/docs/user/en/installation
  • Bench commands: https://frappeframework.com/docs/user/en/bench
  • ERPNext: https://docs.erpnext.com/
Warning

Do not mix random third-party one-click installers with this guide unless you know how they name sites and apps. TripleVox assumes standard Bench: ~/frappe-bench/apps/, sites/.

05. Create site + install erpnext + hrms

  1. From the bench root: bench new-site your.site.name — set Administrator password when prompted.
  2. Get ERPNext: bench get-app erpnext --branch version-16 (confirm branch).
  3. Get HRMS: bench get-app hrms --branch version-16 (confirm branch).
  4. Install: bench --site your.site.name install-app erpnext then install-app hrms.
  5. Create at least one Company (e.g. TITA PP Plastic PLC) via Setup wizard or Company list.
  6. Run migrate and clear-cache.
cd ~/frappe-bench
bench new-site erp.local
bench get-app erpnext --branch version-16
bench get-app hrms --branch version-16
bench --site erp.local install-app erpnext
bench --site erp.local install-app hrms
bench --site erp.local migrate
bench --site erp.local clear-cache
Info

triplevox_platform declares required_apps = ["frappe", "erpnext", "hrms"]. Install those before TripleVox.

06. Install triplevox_platform from GitHub (gmt-erpsol/Triplevoxui → rename folder)

The GitHub repository is named Triplevoxui, but the Frappe app package must live in a folder named triplevox_platform.

  1. cd ~/frappe-bench
  2. bench get-app https://github.com/gmt-erpsol/Triplevoxui.git --branch main
  3. If Bench cloned into apps/Triplevoxui, rename: mv apps/Triplevoxui apps/triplevox_platform
  4. Confirm apps/triplevox_platform/triplevox_platform/hooks.py exists and app_name = "triplevox_platform".
  5. bench --site your.site.name install-app triplevox_platform
  6. bench --site your.site.name migrate && bench --site your.site.name clear-cache
  7. bench build --app triplevox_platform if assets did not soft-link correctly
  8. Restart: bench restart (prod) or restart bench start (dev)
cd ~/frappe-bench
bench get-app https://github.com/gmt-erpsol/Triplevoxui.git --branch main
mv apps/Triplevoxui apps/triplevox_platform   # if needed
bench --site erp.local install-app triplevox_platform
bench --site erp.local migrate
bench --site erp.local clear-cache
bench build --app triplevox_platform
bench restart
Warning

Leaving the folder as Triplevoxui breaks imports and asset URLs. Assets must resolve as /assets/triplevox_platform/....

12. site_config keys reference (triplevox_client, company_profiles, company_themes, theme overrides)

Edit sites/YOURSITE/site_config.json (or use onboarding wizard APIs which write keys safely).

KeyTypePurpose
triplevox_clientstringDefault profile key when no session company map hits (tita/brg/demo)
triplevox_company_profilesobjectMap Company display name to profile key
triplevox_company_themesobjectPer-company overlay (accent, factory_area, logos, etc.)
triplevox_themeobjectSite-wide deep-merge overrides into the active profile

Example site_config fragment

{
  "triplevox_client": "tita",
  "triplevox_company_profiles": {
    "TITA PP Plastic PLC": "tita",
    "BRG Trading PLC": "brg"
  },
  "triplevox_company_themes": {
    "BRG Trading PLC": {
      "factory_area": "Medical Gauze & Silken",
      "accent": "#15803d"
    }
  },
  "triplevox_theme": {
    "partner_name": "TripleVox Engineering PLC"
  }
}

Resolution order (Desk)

  • Session company from Employee.company, else user default Company, else global default.
  • Look up company in triplevox_company_profiles (+ DEFAULT_COMPANY_PROFILES).
  • Load CLIENTS[key], deep-merge triplevox_theme, then company theme overlay.
  • If no company map: use triplevox_client / ACTIVE_CLIENT.
Info

Onboarding wizard writes profiles/themes for you — prefer it over hand-editing JSON in production.

User steps

  1. Log into Desk.
  2. Click the company pill (top-right).
  3. Choose TITA PP Plastic PLC or BRG Trading PLC (or other mapped companies).
  4. Theme accents + watermark update; user default Company is set.

triplevox_platform.api.set_session_companySets user default Company; updates Employee.company when present; returns boot payload

Permissions

  • Apply print pack (current)…

25. Employee Checkin geolocation blink fix

HRMS Employee Checkin can flash a geolocation map/section before HR Settings are known, causing a UI 'blink'.

  • hooks doctype_js maps Employee Checkin → public/js/tvx_employee_checkin.js
  • Script hides geolocation UI until HR Settings confirm it should show
  • Result: no flash of irrelevant map controls for sites that disable geo check-in
# hooks.py
doctype_js = {
  "Employee Checkin": "public/js/tvx_employee_checkin.js",
}

Problem statement

Employee Checkin forms briefly render a map / geolocation block before client scripts know whether HR Settings require location. Users see a flash (blink) of controls that then disappear.

Fix approach

  1. hooks doctype_js loads tvx_employee_checkin.js only on Employee Checkin.
  2. Script starts with geolocation UI hidden.
  3. After HR Settings (or equivalent flags) resolve, show geo UI only if enabled.

Verification

  • Open Employee Checkin with geo disabled in HR Settings — no map flash.
  • Enable geo requirement — map/controls appear without prior blink of the opposite state.
  • Other DocTypes unchanged (doctype_js scoped).

33. FAQ

Can one site serve TITA and BRG?

Yes — that is the primary SaaS shell design. Map both Companies to tita/brg profiles and use the switcher.

Do I need titacustom for BRG?

No. BRG logos ship inside triplevox_platform. titacustom is for TITA MES and TITA SVG logo asset path.

Why is the Desk logo still TripleVox after switching to BRG?

By design. Product chrome stays TripleVox; watermark/accents/prints follow the sister company.

Are role packs full permissions?

No — they are Desk roles / starters. Configure DocPerms as needed.

Where do I change accent colors?

client_theme.py CLIENTS theme dict, or site_config triplevox_theme / triplevox_company_themes overlays.

How do I force browsers to load new CSS?

Bump ?v= in hooks.py, clear-cache, hard refresh.

GitHub repo name vs app name?

Repo Triplevoxui → folder/app triplevox_platform.

Which Print Format should users pick?

Any format named TripleVox … for branded output.
